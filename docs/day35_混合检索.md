# 混合检索（BM25 + 向量 + RRF）

## 结果
| 方案 | Top-1 | Top-5 |
|---|---|---|
| 基线 向量 K=5 | 72.7% | 100% |
| 混合 RRF K=5 | 81.8% | 90.9% |
| 基线 向量 K=10 | 72.7% | 100% |
| 混合 RRF K=10 | 81.8% | 100% |

## 结论
1. **Top-1 提升 9.1 个百分点**（72.7% → 81.8%）
2. **对照组排除了"信息量混淆"**：向量 K=10 仍是 72.7%，
   说明提升来自 BM25 而非扩大候选池
3. **Top-5 在 K=5 时下降 9.1pp**：RRF 重排把向量第 4 名挤出了前 5，
   这是再排序的固有代价，K=10 后恢复 100%
4. **向量 K=5 与 K=10 相同**：88 块语料下向量已饱和，
   BM25 补的是"向量看不见的精确词信息"，不是候选数量

## 工程要点
- **分词决定成败**：默认词典把 "SSE" 切成 S/S/E，虚词参与打分，
  导致命中无关文档。修法：领域词典 + 停用词 + 过滤单字符
- **小语料局限**：88 块时 BM25 的 IDF 统计不稳定，
  换到千级语料效果会更稳定也更明显
- **RRF 分数不可解释**：约 0.03，只能用于排序，不能当相似度
