# Day 36 实验记录：证据校验（拒答能力）


## 1. 目标

解决"问库外问题时模型硬编答案"的问题。
现状：`NO_ANSWER` 只在"检索完全没结果"时触发，但检索**永远会返回 Top-K**。

---

## 2. 实现

| 文件 | 内容 |
|---|---|
| `src/evidence_check.py` | 三种信号 + 四种策略 |
| `src/streaming.py` | 检索后、生成前插入校验闸门 |
| `tests/test_evidence.py` | 16 个离线用例 |
| `scripts/experiments/try_evidence.py` | 四张对照表 |

### 三种信号

| 信号 | 怎么算 | 成本 |
|---|---|---|
| `max_score` | 5 块里的最高相似度 | 0 |
| `keyword_coverage` | 问题实词在 5 块里的出现比例 | 0（本地分词） |
| `llm_judge` | 让模型只看资料判断"能否回答" | 1 次调用 |

---

## 3. 实验数据（16 题评测集，可答 11 / 不可答 5）

### 两类分数分布

```
可答题最高相似度：  0.721 0.707 0.696 0.648 0.588 0.577 0.573 0.537 0.480 0.477 0.455
不可答题最高相似度：0.571 0.285 0.245 0.224 0.133
```

**重叠区 [0.455, 0.571]**，宽度 0.116。

### 关键反例

```
0.571  「LangChain 的创始人是谁？」      不可答
──────────────────────────────────────
0.537   块重合度 500 会怎样               可答
0.480   复盘量化指标的数据来源要求        可答
0.477   接口地址配错的报错类型            可答
0.455   高频操作提取为技能包的商业价值     可答
```

**一道不可答题的相似度，比 4 道可答题都高。**
这是"相似度 ≠ 可答性"最直接的证据。

### 阈值扫描（max_score）

| 阈值 | 不可答识别率 | 可答保留率 | 调和平均 |
|---|---|---|---|
| 0.25 | 60% | 100% | 0.75 |
| **0.30** | **80%** | **100%** | **0.89** |
| **0.40** | **80%** | **100%** | **0.89** |
| **0.45** | **80%** | **100%** | **0.89** |
| 0.50 | 80% | 73% | 0.76 |
| 0.60 | 100% | 36% | 0.53 |

**平台区 0.30–0.45，取中间 0.40。**

理由：0.30 距不可答最高分 0.285 只有 0.015 余量，换语料/换模型极易翻车；
0.40 时下边距 0.115、上边距 0.055，两边都有余量。

### 三信号对比

| 信号 | 识别率 | 保留率 | 调和平均 | 成本 |
|---|---|---|---|---|
| max_score | 80% | 100% | **0.89** | 0 |
| keyword_coverage | 80% | 100% | **0.89** | 0 |
| llm_judge | **100%** | 73% | 0.84 | 1 次调用 |

### 三段式为什么被否掉

重叠区 5 题的覆盖率：

```
可答题覆盖率：  [0.30, 0.33, 0.56, 0.30]
不可答题覆盖率：[0.50]
→ coverage 切不开（不可答的 0.50 比 3 道可答题都高）
```

用 `HIGH=0.60 / LOW=0.45 / coverage>=0.34` 实算：
识别率 80%，**保留率只有 64%**（误拒 4 道可答题）。

**比单阈值差。** 所以最终用 `strategy="score"` + `LOW_SCORE=0.40`。

---

## 4. 最终指标

```
不可答识别率 80%（5 道不可答题拒掉 4 道）
可答保留率  100%（11 道可答题零误拒）
```

**这两个必须成对报。** 全拒答也能让识别率达到 100%。

### 已知漏网

`0.571` 那道「LangChain 的创始人是谁」会被放行。
换成 `llm_judge` 能拒掉它，但保留率掉到 73%——**这是权衡，不是 bug**。

---

## 5. 四个原则

1. **判据有效性 = 两类分布的可分离度**，不是"看起来合理"
2. **指标必须成对**，否则极端策略能刷分
3. **参数在平台区取中间**，不在拐点取最优
4. **先定评估口径再改方案**（三段式被数据否掉）

---

## 6. 踩过的坑

| 现象 | 原因 | 修法 |
|---|---|---|
| 阈值定 0.30 太脆 | 距不可答最高分仅 0.015 | 取平台区中点 0.40 |
| 三段式误拒 4 题 | 重叠区可答题覆盖率天然偏低 | 改用单阈值策略 |
| 编辑器满屏"未解析的引用" | Pylance 不知道 `src/` 在 path | 加 `pyrightconfig.json` |
| 单测只跑了 1 个 | VS Code 点了单个用例的按钮 | 用 `pytest 文件路径` 跑全量 |

## 7. 面试点

| 问题 | 骨架 |
|---|---|
| 怎么防止模型编答案？ | prompt 约束是第一层；第二层是生成前证据校验，低于阈值直接拒答。实测 80% / 100% |
| 只用相似度行吗？ | 有盲区：不可答最高 0.571 比 4 道可答题还高，那一道必然漏 |
| 为什么不用 LLM 判断？ | 识别率 100% 但误拒 3 题（保留率 73%）。**误拒代价更高**，所以选阈值法；医疗/金融场景会反过来 |
| 方案的缺点？ | 有已知漏网、阈值要按语料重校、覆盖率接管中间区会误伤 |
