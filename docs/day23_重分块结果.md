# 重分块实验结果

## 实验设计
- 对照组：原 collection（61 块，中位块长 70 字）
- 实验组：重分块（chunk_size=400 / overlap=80）
- 评测集：20 题（11 可答），关键词匹配，单块需命中 ≥2 个关键词

## 结果
| 方案 | Top-1 | Top-K |
|---|---|---|
| v1 基线 K=9 | 54.5% | 90.9% |
| v2 基线 K=9 | 72.7% | 100.0% |
| v2 基线 K=5 | 72.7% | 100.0% |
| v2 相邻扩展 K=3 | 72.7% | 90.9% |

## 结论
1. 分块过碎是 Top-1 的瓶颈，重分块后 +18.2pp
2. K=5 与 K=9 效果相同 → 上下文可减半
3. 相邻块扩展在分块修复后失效，属于补丁而非优化，已移除

## 已知局限
Top-1 剩 3 题未命中，可能是"答案跨块"，单块凑不到 2 个关键词，
指标对这类题偏严。

注：相邻块扩展在 v2 上表现下降，经查是 id 编号使用全局序号导致邻居取错， 该结论需在修正 id 后重测。不影响"重分块提升 Top-1"的主结论。
