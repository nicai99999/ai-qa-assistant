TCP 三次握手
第一次：客户端发送 SYN=1，序号 seq=x
第二次：服务端返回 SYN=1，ACK=1，seq=y，ack=x+1
第三次：客户端发送 ACK=1，ack=y+1
为什么是三次而不是两次：为了确认双方的收发能力都正常。
如果只有两次，服务端无法确认客户端的接收能力，也无法防止历史连接请求造成的错误。

UDP 与 TCP 的区别
1. UDP 无连接，TCP 面向连接
2. UDP 不保证可靠交付，TCP 提供可靠交付
3. UDP 首部只有 8 字节，TCP 首部至少 20 字节
4. UDP 适合实时音视频，TCP 适合文件传输

HTTP 与 HTTPS
HTTP 明文传输，端口 80。
HTTPS 加入 TLS/SSL 加密，端口 443。
HTTPS 能防止中间人攻击，但同样会被抓包看到目标 IP。
证书链的验证是 HTTPS 安全的核心。
